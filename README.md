# 工具箱

一个 iOS 原生视频工具箱。粘贴地址即播，带内置浏览器嗅探、后台下载、多播放列表、WebDAV、局域网互传与投屏，另带签到、积分和派猫猫旅行。

- 原生 SwiftUI，iOS 14 起
- 数据全部存在本机，不上传任何服务器
- 未上架 App Store，需要自己签名安装

## 安装

准备一台 Windows 或 Mac、一根数据线、一个 Apple ID，加上 `VideoLinker-unsigned.ipa`（安装包文件名沿用了旧名，装好后桌面显示「工具箱」）。

用 Sideloadly 签名装进手机，全程免费。免费账号签的包 **7 天有效**，到期重签一次即可，数据不会丢。

完整步骤（含信任证书、开发者模式、常见报错）见 **[安装教程.md](安装教程.md)**。

想自己出包：

| 方式 | 需要 | 说明 |
| --- | --- | --- |
| Xcode | 一台 Mac | 打开 `VideoLinker.xcodeproj`，选自己的手机按 ⌘R |
| GitHub Actions | 一个 GitHub 仓库 | 推代码自动编译，在 Artifacts 里取 ipa |

## 功能

底部五个标签：**播放、列表、签到、嗅探、设置**。

### 播放

- 粘贴地址即播，支持 mp4 / mov / m4v 直链与 m3u8 直播流
- 输入框可以直接粘一**整段分享文案**，会自动把里面的网址挑出来
- 右上角全屏按钮，系统直接把屏幕转成横屏，不用自己转手机
- 手势：上下滑调亮度 / 音量，左右滑拖进度，双击快进，长按 2 倍速
- 画中画、AirPlay 原生支持，锁屏和切后台继续播
- 外挂字幕：srt / vtt / ass，本地视频自动找同名同目录字幕，字号可调
- 右上角 ⋯ →「技术信息」：容器、编码、分辨率、帧率、码率、HDR、音轨参数，可一键复制
- 记住每条的观看进度，看到结尾按钮变「重播」
- **自定义请求头**：按域名配 Referer / Cookie / UA，解决「网页能打开、播放 403」的防盗链源
- **画面调节**：左 / 右转 90°、水平 / 垂直镜像、1–300% 缩放，竖拍和镜像素材都能摆正；另有适应 / 填充 / 拉伸 / 16:9 / 4:3 五种画面比例，宽银幕和老片的黑边能压掉，全部按视频记住
- **手势自定义**：横向滑进度 / 亮度 / 音量、纵向滑音量 / 亮度、双击跳 5–30 秒或播放暂停、长按 2× / 3× 可选
- **音画同步**：蓝牙耳机延迟补偿 -300～+300 ms，按输出设备记住
- **Live Photo**：把当前画面前后 3 秒存成实况照片，可直接设动态壁纸
- **二维码分享**：当前视频地址生成二维码，另一台手机扫码即开
- **语音生成字幕**：没有字幕的课程 / 生肉视频，用系统语音识别在本机转成 srt，音频不上传；支持中 / 英 / 日 / 韩 / 粤语
- **下一集预加载**：连播时提前把下一集放进播放队列，切集基本秒开，不用再等握手和首片

### 列表

- 可建多个播放列表，内置一个「下载」列表；从任意一条开始顺序连播
- 每行底部有 3pt 观看进度条，右侧显示「看到 42%」；在线条目自动抓网页封面
- 长按列表卡片可重命名 / 置顶 / 删除；长按视频条目可改名
- 排序：名称 A→Z、Z→A、视频多的在前、最近创建、最早创建，也能手动拖动
- **封面墙**：列表可一键切九宫格，按封面找片，多选与长按菜单照旧
- 本机视频：扫描并导入 App 里的视频，支持从「文件」App 多选、iCloud 未下载的文件，也能直接从系统相册导入；覆盖安装后列表里的旧路径会自动找回，不会显示成已删除
- 存储管理：按大小列出文件，标出重复 / 未进列表 / 已看完，一键清理并同步删掉死条目
- **占用条**：存储页顶部用色条分出「已在列表 / 未进列表」，每行还有相对占比细条，谁在吃空间一眼看出
- **画面查重**：抽每个视频的一帧算 64 位指纹，同一部片的不同清晰度也能认出来；按组选保留哪条，播放列表记录和进度自动迁过去
- **私密保险箱**：长按列表移入，列表页不再显示；左上角 ⋯ 里验证面容 ID 后查看，切后台自动收回
- **删除可撤销**：删掉的条目在底部留六秒，点「撤销」按原位置放回去，批量删除也支持

### 下载

- 后台下载，锁屏、切后台、被系统回收后重开都能接着跑
- 暂停 / 继续 / 重试；HLS 按分片续传，只补缺的片
- 同时下载数量 1–5
- 完成后可导出到「文件」App、存进相册或走分享面板
- 列表显示首帧缩略图、时长、实时速度与进度
- **边下边看**：m3u8 没下完也能播，已下好的分片先放，缺的由本地中转补
- **队列优先级**：拖动排序、置顶优先下载、整队暂停 / 继续
- **失败自动换源**：一条地址 403 / 超时，自动换同页抓到的其它清晰度、http 与 https 互换的地址；也能在长按菜单里自己填备用源，失败卡片显示「源 2/3」
- **分段并行下载**：30 MB 以上的直链切最多 4 段同时拉，暂停继续按段续传，服务器不认 Range 自动退回单线程
- **HLS 清晰度选择**：m3u8 有多档码率时，下载前先挑 1080p / 720p / 480p，带分辨率和码率参考
- **下完自检**：直链下完先核对字节数，MP4 再读一次时长；服务器提前断流、文件少半截的会被拦下来，自动删掉重下一次，不会等点开才发现放不了

### 嗅探

- 输入网址后用内置浏览器扫描 `<video>`、`<source>`、`fetch`、`XHR` 四种来源
- 结果按 HLS / MP4 / 其他分类，支持多选后批量下载、批量加入列表、批量复制
- 每行显示域名、时长、分辨率
- 右下角悬浮球短按直接抓这一页最像正片的地址
- **图片 / 图集**：同一页面里的 `<img>`、`srcset` 和图片链接也会抓，九宫格预览，多选存相册或复制链接
- **自动滚动收集**：懒加载的长页面 / 图集，菜单里点一下自动往下滚，边滚边收，到底自动停
- **选中即存**：在网页里选中一段字，选区下方浮出「存备忘」，点一下连页面标题和地址一起存进备忘录；菜单里另有「存到备忘录」，没选字就存整页
- **同片合并**：同一部片的 1080p / 720p / 预览地址按文件名归成一组，一条只占一行，点「N 档」再挑清晰度；已知只有几十秒的广告片自动排到最后

### 签到（底部五标签之一）

页面底部有三段切换：**签到、积分、旅行**。

- 多账号，国内版 `codebuddy.cn` 与国际版 `workbuddy.ai` 可切
- 一键签到，每天首次打开 App 自动补签，当天签过的不重复请求
- 积分：总积分、剩余 / 总量、最近到期，7 天内到期会标橙
- 派猫猫旅行：查状态、一键派发、到达后领奖，页面停留时每 60 秒自动刷新
- 接口路径放在 `wb-endpoints.json`，官方改路径时只改这份文件，App 重启生效，不用重新装包。设置 → 关于 →「签到接口」可查看当前配置、填自定义地址或直接粘贴导入

### 设置

- 主题（跟随系统 / 浅色 / 深色）、**六套主题色**、**可选桌面图标**、字幕字号
- **换机搬家**：把列表、进度、备忘、书签、脚本打成 AES-GCM 加密包，新机输同一个密码导入，重启后整套换过去；导入前自动留一份 `restore-backup.sqlite`
- **多设备同步**：WebDAV 上放一份 JSON 快照，双向合并播放列表、备忘、书签和观看进度，同一条取更新的那份
- **网站数据**：按站点列出 Cookie、缓存、本地存储，能单独清某一个站，不用整锅端
- **WebDAV 网络存储**：浏览 NAS 目录，点视频直接播，密码存系统钥匙串
- **局域网收件箱**：手机开 HTTP 服务，电脑浏览器打开 `http://手机IP:8080` 把视频拖进去
- **局域网互传**：两台手机都装工具箱，打开「接收」后能在对方列表里看到设备，选视频直接点发送，双向都行，不经过服务器
- **局域网投屏**：电脑浏览器打开 `http://手机IP:8088` 直接看手机里的视频，进度条可拖
- **接收投屏**：手机广播成 DLNA 播放器，别的设备投屏时能选到「工具箱」，推过来直接本机播
- **观看统计**：本周 / 今天 / 累计时长、近 7 天柱状图、常看来源、看得最多的片子
- **App 锁**：面容 ID / 触控 ID，可设立即 / 1 分钟 / 5 分钟宽限
- **网络诊断**：网络类型、本机 IP、DNS 解析、延迟抖动、实测下载速度，结果可复制
- **手势与手感**：手势分工、双击秒数、长按倍速，以及触感 / 动效开关
- **备忘录**：设置里的随手记，链接、账号、临时要记的东西都能粘进来；支持搜索、复制全文、只复制链接、分享，删错了六秒内可撤销
- **定时巡检**：指定追更页面，按 6 小时 / 12 小时 / 每天 / 3 天去抓一次，发现新的 mp4、m3u8 自动入队；后台由系统调度，前台可立即运行
- 下载并发数、存储管理、观看统计、签到接口、关于

> 局域网收件箱和投屏需要「本地网络」权限，App 会在你打开对应页面时主动申请。

## 全屏是怎么实现的

`OrientationLock.swift` 用 iOS 16 的 `requestGeometryUpdate` 请求转向，这是公开接口，不是私有 API。平时整个 App 锁竖屏，点全屏按钮时锁横屏并铺满，退出或把手机竖回来时自动恢复。

## 数据存在哪

### SQLite（v2.7.0 起）

App 用 GRDB 把数据统一存在一个 SQLite 库里：`Application Support/VideoLinker/videolinker.sqlite`（目录与文件名沿用旧名，改显示名不影响已有数据）。

- 表：`history`（播放历史）、`resume`（观看进度）、`favorite`（收藏）、`playlist` / `playlistItem`（播放列表）、`script` / `scriptValue`（用户脚本与 GM 存储值）、`download`（下载记录）、`webVisit`（网页历史）、`bookmark`、`shortcut`、`memo`（备忘录）
- 首次升级会把旧版 UserDefaults 里的 JSON 全量搬进库，搬之前先备份成 `legacy-backup-<时间>.json`
- 写入仍然双写 UserDefaults，装回旧版本也能看到全部数据
- 设置 → 关于 里能看到库体积；一致性校验页在 v2.7.3 移除（迁移验证完成后不再需要）

## 版本记录

> 只保留最近 5 条。发新版时把第 6 条起删掉，更早的记录看 git 历史。

### v1.7.0 媒体服务器、FTP / SFTP、Siri 语音控制

- **媒体服务器**：设置 → 网络存储 → 媒体服务器。手机变成一台 DLNA 片源，同一 Wi-Fi 下的电视 / 投影在「媒体服务器」列表里能看到「工具箱影库」，进「全部视频」或按文件夹浏览，点开即播。流服务支持按需 Range 读取，拖进度条不用整份下载；离开设置页不会自动关，电视正播着也能继续供片
- **FTP / SFTP**：设置 → 网络存储 → FTP / SFTP。FTP 走被动模式（PASV + MLSD，老服务器自动退回 LIST），SFTP 走 Citadel 的 SSH 密码登录；两种都能列目录、看大小、按字节范围读，播放同样走本地流代理
- **Siri 与快捷指令**：新增「继续看上次的视频」和「播放指定视频」两个动作，可以直接说「用工具箱继续看」「用工具箱播放 老友记」，也能拼进快捷指令
- **顺手修掉**：SMB 流地址拼接少了个斜杠，个别播放器会认不出本地代理地址

### v1.6.0 压缩包工具、局域网影库

- **压缩包**：设置 → 文件 → 压缩包，直接浏览和解开 zip、tar、tar.gz（下载目录里的自动列出来，也能从「文件」App 选）。解压带进度、路径穿越防护，解开到「下载/解压/<包名>」。rar、7z 没有可用的公开库，检测到会说明，请先在电脑上解压
- **局域网影库**：设置 → 网络存储 → 局域网影库。DLNA 媒体服务器自动发现（NAS 打开媒体共享即可），目录浏览直接播；SMB 共享手动填主机、共享名、账号密码（密码存钥匙串），播放走本地流代理按需读，不整文件下载
- **两个入口都在设置里**：影库在「网络存储」卡片，压缩包是独立的「文件」卡片

### v1.5.1 桌面图标切换修好

- **图标真的会变了**：之前五套图标只在资源目录里，没有作为文件打进 App 包，系统按名字找不到图，就一律显示成占位网格。现在五套图连同 iPhone、iPad 各尺寸一起进包，Info.plist 按文件名逐个登记，选哪套就是哪套
- **珊瑚色回到默认**：选「珊瑚」等于恢复默认图标，不会留下一个改不回去的派生图标

### v1.5.0 换机搬家、多设备同步、定时巡检、主题色与图标、网站数据

- **换机搬家**：整库用 `VACUUM INTO` 取一致快照，连同偏好设置一起打包，AES-GCM 加密（密码 SHA-256 迭代 2 万次派生）。新机选包输密码，数据落到 `pending-restore.sqlite`，下次启动在数据库打开前替换，替换前自动备份
- **多设备同步**：WebDAV 上维护一份 `VideoLinker/sync.json`。列表按条目 id + 地址双重去重合并，备忘按更新时间取新，书签按地址去重，进度取更新的那条。删除不传播，宁可多留不误删
- **定时巡检**：页面里的绝对视频地址和 `src` / `data-src` 属性都会抓，支持关键字过滤，同一条地址只下一次。后台走 `BGAppRefreshTask`，按系统节奏跑
- **主题色与图标**：珊瑚、海蓝、薄荷、紫罗兰、樱粉、石墨六套配色，强调色和渐变一起换；配套五套桌面图标，可在设置里切换
- **网站数据**：按域名列出 WebKit 保存的 Cookie、缓存、IndexedDB 等，单站清除和全部清除

### v1.4.0 画面比例、下载自检、嗅探合并

- **画面比例**：播放页「画面调节」新增适应 / 填充 / 拉伸 / 16:9 / 4:3 五档。填充铺满屏幕、裁掉多余部分；拉伸会把画面拉变形，用来校正非方形像素；16:9 和 4:3 把宽银幕、老片的黑边压掉。和其他画面设置一样按视频记住
- **下完自检**：直链下完先比对服务器声明的字节数，MP4 再读一次时长。服务器提前断流、文件少半截的，自动删掉重下一次；第二次还坏就标红停下，不会等进了列表点开才发现放不了
- **嗅探合并**：同一部片的多个清晰度按「同域名 + 去掉 1080p / 720p 标记的文件名」归组，一条占一行，右边标「N 档」，点开再挑。组内默认取最清晰的一条播放或加入列表，复制能一次复制全部地址；已知只有几十秒的广告片排到最后
- **兼容旧记录**：画面调节新增了比例字段，旧版本存的角度、镜像、缩放继续有效，不会因为多一个字段就整个重置
