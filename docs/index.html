安装步骤

  1. 下载 ipa：点上面的按钮，得到 VideoLinker-unsigned.ipa，不用解压。
  2. 电脑装 Sideloadly：Windows 或 macOS 都行，从 sideloadly.io 下载安装。
  3. 手机连电脑：数据线插上，解锁手机，弹「信任此电脑」时点信任。
  4. 拖进 Sideloadly：把 ipa 拖到窗口里，Apple ID 填自己的，点 Start，等进度条走完。
  5. 信任证书：手机上打开 设置 → 通用 → VPN 与设备管理 → 点你的 Apple ID → 信任。
  6. 打开开发者模式：iOS 16 及以上，设置 → 隐私与安全性 → 开发者模式 → 打开并重启。

免费 Apple ID 签的包 7 天到期，重新签一次即可，App 里的数据不会丢。详细报错处理见 安装教程。

常见问题

装完点图标闪退，或者提示「未受信任的开发者」

证书没信任。去 设置 → 通用 → VPN 与设备管理，找到你的 Apple ID 点「信任」。iOS 16 以上还要在 隐私与安全性 里打开开发者模式。

7 天后打不开了

免费账号的签名有效期是 7 天。重新用 Sideloadly 签一次、覆盖安装即可，本地数据会保留。

换手机，数据怎么带走

旧机打开 设置 → 换机备份，勾选「包含网站数据」生成备份包；把包传到新机，新机同一页面选择备份包导入，重启 App 后生效。

为什么不上架 App Store

应用包含网页嗅探与后台下载能力，不符合 App Store 审核要求，只能以自签方式分发。所有数据都存在本机，不上传任何服务器。
